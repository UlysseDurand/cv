# readme2html

This project is intended to deploy a README.md to a gitlab page.

Just copy this `.gitlab-ci.yml` with your own parameters for the readme2html command to your project root and it should work.

You can see the result [here](https://ulysse_durand.gitlab.io/cv/readme2html)
